# Flashforge Creator Pro 2 + Orca Slicer

Конвертер поддерживает **обычную** печать на Creator Pro 2: правой головкой
(T0), левой (T1) и независимую двухголовую печать. Настройки соответствуют
присланному профилю Orca: её экструдер 0 — физическая левая головка T1,
экструдер 1 — правая T0. Значения режима и последних байтов GX (`1`, `07 07`)
соответствуют вашему скрипту `ffcp2_orca_sd.py`.

Для конвертации файла в Orca укажите расширение `.gx`, а в поле
**«Скрипты постобработки»** — команду с явным
профилем:

```text
"C:\path\to\gcode_to_gx.exe" --printer creatorpro2
```

Путь к временному файлу Orca подставляет сама — добавлять его не нужно.

Если у вас уже настроен `ffcp2_export_dialog.bat` с `ffcp2_orca_sd.py`,
оставьте его: этот скрипт сам создаёт и передаёт `.gx`. Дополнительный
конвертер ему не требуется. Уже готовый `.gx` обработчик передаёт дальше,
не добавляя вторую шапку.

## Машинный G-code

Конвертер добавляет шапку GX и миниатюру. Команды нагрева и смены головок он
не меняет. Нужен настроенный для Creator Pro 2 профиль принтера в Orca.
Перед печатью проверьте, что нарезанный G-code содержит:

- `M118 ... T0` для правой головки, `M118 ... T1` для левой или
  `M118 ... T0 T1` для независимой двухголовой печати. Укажите правильные
  пределы X/Y/Z своего принтера. Для печати только левой головкой эта команда
  также позволяет конвертеру записать расход и температуру в поля T1.
- `M108 T0` / `M108 T1` для выбора и парковки головок. Отдельные `T0` / `T1`
  в вашем профиле используются для отображения температуры в Orca, а не для
  физической смены головки.
- Подходящие для принтера команды нагрева и парковки. В работающем
  [профиле сообщества для PrusaSlicer](https://github.com/Jacotheron/FlashForge-CreatorPro2-PS-Profile)
  используются `M140`/`M104` с параметром `T`, ожидание нагрева `M7`/`M6`,
  а также `G28` и `M132`. Синтаксис подстановок PrusaSlicer перед использованием
  в Orca нужно адаптировать. Значения некоторых полей GX в опубликованном
  профиле отличаются от вашего скрипта, поэтому здесь взяты значения из
  вашего работающего варианта.

Зеркальный режим и дублирование пока не поддерживаются: им нужны другая шапка
и калибровочная площадка. При `M118 ... D1/D2` или `M109 T1/T2` конвертер
выдаёт ошибку и сохраняет исходный файл без изменений.

Автоматические тесты проверяют структуру и поля `.gx` по вашему профилю Orca
и скрипту экспорта. Проверки печатью на физическом принтере здесь
не было. Начните с небольшого задания в обычном режиме. Если принтер не
принимает файл, сравните шапку с рабочим `.gx` от FlashPrint с помощью
`scripts/calibrate_header.py`. При ошибке «File open failed» попробуйте также
короткое имя файла.
